# Third-party dependencies

This project uses the following published libxposed 102.0.0 artifacts:

- `io.github.libxposed:api:102.0.0` (compile only)
- `io.github.libxposed:interface:102.0.0`
- `io.github.libxposed:service:102.0.0`

Copyright belongs to the respective libxposed contributors. The artifacts' Maven Central POMs declare the Apache License 2.0; those POMs and the Apache license text are included in `libs/`. The API is provided by the framework and is not bundled into the APK. The interface and service classes are bundled.
