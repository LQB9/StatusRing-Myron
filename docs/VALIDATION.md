# 验证范围

目标为 README 列出的 myron / Android 16 / HyperOS 3 组合。

## 已完成

- APK v3 签名与 zipalign 对齐检查。
- 35 项 JVM 行为检查，包括各卡制式、服务状态、充电单双闪电、动画起始／结束、快速反向切换与禁用动画。
- 86 项手机 Android Canvas 示例绘制检查，包括三种布局、单卡／无卡、三位电量、最大右侧字号，以及动画中间帧在不同高度下的裁切检查。
- 既有 36 项目标 SystemUI 二进制接口核对，当前版本未改变注入接口。
- 历史真机验证包括模块接管、普通 USB 充电、总开关恢复、设置页重建与重启按钮；充电胶囊闪回修复曾通过物理重插和绘制前状态检查。
- v1.0.11 的设置页预览已录制并抽查中间帧，包含快速反向切换；预览使用示例状态，真实电池读数未伪造。

## 尚未完整覆盖

- 其他机型、ROM 或系统更新后的接口。
- 通过实际拔卡／禁用订阅验证的单卡与无卡切换。
- 当前版本物理拔线时的状态栏动画和快充视觉切换。
- 长时间运行、所有网络注册组合、快速 Wi-Fi 压力切换。
- 完整的 AOD、锁屏、通知／控制中心、浅色界面和 TalkBack 回归。

示例绘制通过不代表上述未覆盖场景已经验证。测试版本保留原生恢复路径，遇到问题可先关闭模块总开关。
