# 验证范围

本版 v1.0.14 实机环境为 README 列出的 myron / Android 16 / HyperOS 3 组合。其他设备属于接口探测模式，尚未实机验证。

## 已完成

- APK v3 签名与 zipalign 对齐检查。
- 49 项 JVM 行为检查，包括各卡制式、服务状态、充电单双闪电、动画状态，以及缺失可选接口、继承方法、不同资源更新后缀、Compose 槽位、多宿主数据隔离和未知信号回退。
- 99 项手机 Android Canvas 示例绘制检查，包括三种布局、A 上下圆点一致与开口留白、单卡／无卡、三位电量、最大右侧字号，以及三种布局的动画中间帧裁切检查。
- APK 中 284 个 Android 方法引用对照 SDK API 版本历史，未发现高于 API 31 的公开方法需求。广播注册按 API 33 分支；这属于静态检查，不代表 Android 12 已实机验证。
- 保留历史 36 项目标 SystemUI 二进制接口核对记录。本版将部分接口改为可选，新的运行时探测已在当前 ROM 实机通过。
- v1.0.14 已后台覆盖安装，在实际状态栏确认 A / B / C 切换；A 的双卡圆点、Wi-Fi、真实 USB 普通充电单闪电和右侧电量正常。
- 实际点击总开关，确认关闭后恢复原生双卡、Wi-Fi、电量，重新启用恢复模块；当前用户配置在检查后保持不变。
- 实际点击设置页重启按钮，确认记录重启请求并更换 SystemUI PID，随后重新接管。
- 实际打开兼容检测页，确认读取 SystemUI 运行报告；ADB 普通 Shell 对诊断 Provider 的未授权写入被拒绝。
- A 的 86% 常规预览、100% / 140% 线宽压力预览均使用 APK 原生绘制生成并目视核对；不含个人手机通知或照片。
- 历史真机验证包括模块接管、普通 USB 充电、总开关恢复、设置页重建与重启按钮；充电胶囊闪回修复曾通过物理重插和绘制前状态检查。
- v1.0.11 的设置页预览已录制并抽查中间帧，包含快速反向切换；预览使用示例状态，真实电池读数未伪造。

## 尚未完整覆盖

- 其他机型、ROM、Android 12–15 / 17，以及系统更新后的接口。合成契约检查不能替代这些实机验证。
- 通过实际拔卡／禁用订阅验证的单卡与无卡切换。
- 当前版本物理拔线时的状态栏动画和快充视觉切换。
- 长时间运行、所有网络注册组合、快速 Wi-Fi 压力切换。
- 完整的 AOD、锁屏、通知／控制中心、浅色界面和 TalkBack 回归。

示例绘制通过不代表上述未覆盖场景已经验证。测试版本保留原生恢复路径，遇到问题可先关闭模块总开关。
