# 兼容策略

v1.0.14 从指定机型入口改为运行时接口检测，目前只有 MIUI / HyperOS 宿主适配器。

| 环境 | 状态 |
| --- | --- |
| myron / OS3.0.308.0.WPMCNXM / Android 16 / SystemUI 16.03.251211.r | 已核对接口并真机回归，范围见 VALIDATION.md |
| 其他 MIUI / HyperOS，Android 12 及以上 | 实验兼容；需要核心宿主、具体状态栏容器和信号视图接口匹配，尚未实机验证 |
| ColorOS / One UI / AOSP 等 | 尚无对应宿主适配器，缺失接口时保留原生 |
| Android 11 及以下 | 不支持安装；蜂窝监听依赖 Android 12 的 TelephonyCallback |

## 检测与回退

- 核心要求 `MiuiBatteryMeterView` 为 ViewGroup，并具备 int 类型电量字段、厂商的附着／分离、测量、布局方法。核心安装失败会撤销核心钩子并保留原生。
- 宿主向上搜索 `MiuiStatusBatteryContainer`，不要求固定父子层级。宿主标签未知时只识别已知的手机状态栏／锁屏祖先，未知位置不接管，AOD 不启用。
- 信号按实例的 `getSlot()` 识别 `wifi`、`mobile`、`stacked_mobile`，并保留经典视图的类名后备。运行时探测实际图标类的可见性方法，以兼容部分 Compose 包装结构。
- 只在该宿主内、读数和可见性接口同时可用时接管对应信号槽。某项失败不阻止电池绘制，也不会隐藏该项原生图标。无法读取任一有效 SIM 的订阅时，整组蜂窝信号保持原生，避免缺失某张卡。
- 卡槽读数、网络制式仍通过 Android 每订阅监听分别读取。厂商信号等级接口缺失时使用标准等级，不复制上网卡的网络制式给另一张卡。
- 网速字体、资源更新回调、快充字段、原生文字颜色、充电岛和测量去优化分别处理。网速资源回调接受无参 `updateResources` 及数字后缀形式，不固定 `$4`。
- 缺少快充字段时显示普通充电。仅当充电岛恢复所需接口齐全且钩子安装成功时覆盖充电岛隐藏请求；否则随原生显隐。没有电池宿主时仍可以接收设置页的手动重启请求。
- 最低安装版本 API 31；广播接收器按 Android 13 的规则分支注册。降低安装门槛没有增加 Android 11 及以下的旧式蜂窝监听实现。

## 运行报告

设置页的「查看兼容检测」显示 SystemUI 实际安装钩子、读取状态和每个宿主的接管情况。不同启动或模块版本的旧记录会被标注。报告由 SystemUI UID 写入模块的专用诊断 Provider，其他应用不能写入；不提供广播命令、文件访问或执行 Shell 的接口。

报告用于判断缺少哪些接口。出现「接口可用」只能说明探测通过，不能替代该 ROM 的实机验证。
